# Wacky Wok — Vercel-ready website

Static responsive website. Deploy by importing this repository into Vercel; no build command or environment variables are required.

## Deployment
1. Create a separate GitHub repository for Wacky Wok.
2. Upload the contents of this folder to the repository root.
3. In Vercel, Add New → Project → import that repository → Deploy.
4. Add the confirmed phone number in `script.js` at `WACKY_WOK_PHONE` (digits only, Pakistan format e.g. 923001234567), commit and let Vercel redeploy.
5. Replace illustrative stock food photos with approved Wacky Wok product photos before public launch.
